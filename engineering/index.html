SPACE SYSTEMS IN DEVELOPMENT

CubeSat Attitude
Control Simulator

How do you keep a spacecraft pointing in the right direction? A personal 3U CubeSat simulation exploring dynamics, orbital motion and quaternion-based control.

  • Python
  • ADCS
  • Quaternions
  • RK4
View source & documentation ↗
Objective
Model how a 3U spacecraft maintains its orientation.
What I built
Rigid-body dynamics, orbital propagation, quaternion-based PD control, modeled sensors, telemetry and automated tests.
Tools
Python · quaternions · RK4 integration
Current outcome
A software simulation for exploring attitude dynamics and control. Hardware integration remains on the roadmap.
Approach & next steps +

Approach: model rigid-body motion, integrate the dynamics and apply PD control to spacecraft orientation. Telemetry and automated tests support inspection of the implementation.

Next steps: sensor-based estimation, a MATLAB/Simulink twin and an ESP32 firmware port.
